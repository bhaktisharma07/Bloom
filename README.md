# Bloom 

Bloom is a minimalist habit tracking web application designed to help users build consistency through simple daily habit tracking, progress monitoring, and streak analytics.

## Features

* Track daily habits
* Create, edit, and delete habits
* Daily progress tracking
* Streak monitoring
* Weekly performance analytics
* Monthly activity overview
* Local storage persistence
* Data backup and restore

## Tech Stack

* React
* Vite
* JavaScript
* CSS

## Status

🚧 Currently in Development

Built as a learning project to explore React, state management, local storage, and UI/UX design.
